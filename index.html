Classificação Oficial das Faixas de Portas IANA (1 - 65535)

O espaço de endereçamento de transporte TCP e UDP utiliza campos de 16 bits, totalizando 65.535 portas utilizáveis divididas em três faixas oficiais:

Intervalo de Portas Classificação IANA Quantidade Comportamento e Uso Típico
0 – 1023 Well-Known / System Ports 1.024 portas Reservadas para protocolos fundamentais da internet e serviços de sistema (HTTP, SSH, DNS, SMTP, SMB). Em sistemas Unix/Linux, exigem privilégios de superusuário (root / CAP_NET_BIND_SERVICE) para escuta. (A porta 0 é reservada pelo kernel).
1024 – 49151 Registered / User Ports 48.128 portas Atribuídas pela IANA mediante solicitação para aplicações comerciais, bancos de dados, painéis web, APIs e serviços de usuário (MySQL 3306, RDP 3389, PostgreSQL 5432, HTTP-Alt 8080). Podem ser abertas por processos sem privilégio de root.
49152 – 65535 Dynamic / Private / Ephemeral 16.384 portas Não podem ser registradas oficialmente na IANA. Utilizadas pelo sistema operacional como portas de origem temporárias (efêmeras) para conexões de saída dos clientes, serviços internos dinâmicos (como RPC dinâmico do Windows) ou aplicações customizadas privadas.
